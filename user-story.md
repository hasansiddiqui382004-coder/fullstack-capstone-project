# GiftLink - User Stories & Agile Requirements

This document outlines the user stories for the GiftLink full-stack web application, defining core functionalities from the perspective of our users.

---

## 1. User Authentication & Profile
* **As a** new visitor, 
  **I want to** register an account with a secure password and email, 
  **So that** I can securely access the platform and list or claim items.

* **As a** registered user, 
  **I want to** log in using my credentials, 
  **So that** my session is authenticated via JSON Web Tokens (JWT).

* **As a** user, 
  **I want to** update my profile information (such as my display name or contact details), 
  **So that** other community members can reach me easily.

---

## 2. Gift Management & Listings
* **As a** user wanting to give away items, 
  **I want to** create a new item listing with a title, description, category, condition, and image, 
  **So that** people looking to recycle or find free household items can discover them.

* **As a** browsing user, 
  **I want to** view a complete catalog list of all available gifts on the main page, 
  **So that** I can browse what items are currently being given away.

* **As a** interested user, 
  **I want to** click on an individual item to see its detailed description and information, 
  **So that** I can decide if it meets my needs.

---

## 3. Search & Community Interaction
* **As a** user looking for specific items, 
  **I want to** filter gifts by category or use search functionality, 
  **So that** I can quickly find what I am looking for without scrolling through everything.

* **As a** community member, 
  **I want to** leave comments or reviews on item listings, 
  **So that** I can ask questions or coordinate pickup details with the donor safely.
